# UlockAI - Security SDK for AI Agents

Protect your AI applications, LLMs, and SLMs from real-world vulnerabilities like **Prompt Injection**, **Memory Poisoning**, and **API Misuse**.

This repository contains the landing page for **UlockAI**.

## ✨ Features
- **Modern Design**: A sleek, dark-themed developer-first aesthetic.
- **Fast Performance**: Built with pure HTML/CSS/JS for rapid load times.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **GitHub Pages Ready**: Simple structure, easy to deploy.

## 🚀 Deployment
This site can be deployed instantly using GitHub Pages:

1. Push this folder to your GitHub repository.
2. Go to **Settings** > **Pages**.
3. Select the `main` branch and `/root` (or the folder where these files are located).
4. Click **Save**.

## 🛠 Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom properties (Variables), Grid, Flexbox, Animations.
- **Vanilla JS**: Subtle interactions and copy-to-clipboard functionality.
- **Google Fonts**: Inter & Outfit.

## 📦 SDK Installation
If you're looking for the Python SDK, install it via pip:
```bash
pip install ulockai
```
